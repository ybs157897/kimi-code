### 1. TeamMailbox 运行时（新文件 `expert-team/runtime.ts`）
- 内存事件直投（非 WorkBuddy 的 2s 轮询），挂在 Session、与 `activeExpertTeam` 同生命周期
- roster：lead(main) + 成员 `{name, agentId, status: idle|running|shutting_down}`
- 投递到 lead：包装 `<teammate-message teammate_id summary>`（复用 `renderNotificationXml` 模式，notification-xml.ts:26-49）→ `main.turn.steer()`（turn/index.ts:167-184：忙则并入 steerBuffer、闲则 launch 新 turn——天然等价 WorkBuddy 的入队/唤醒二选一）；origin 用 `{kind:'system_trigger', name:'teammate'}`
- 投递到成员：running → steer 成员 turn；idle → 经 `SessionSubagentHost.resume`（subagent-host.ts:179）wake 一轮
- 未投递信件 journal 持久化到 session metadata，restore 时重放

### 2. SendMessageTool（新文件 `tools/builtin/collaboration/send-message.ts`）
- zod：`type: message|broadcast|shutdown_request|shutdown_response`，`recipient`、`summary`、`message`、`request_id`、`approve`
- 注入方式仿 AgentTool 构造注入（agent.ts:107-134）；注册进 `initializeBuiltinTools`（tool/index.ts:837-906，gated on mailbox 句柄）；加入 `DEFAULT_APPROVE_TOOLS`（default-tool-approve.ts:3-26）；加入 lead/member profile tools 列表（expert-team/index.ts:44-45,128,156）
- Session→Agent 句柄链路：仿 `subagentHost` 在 AgentOptions 加可选 mailbox 句柄，session/index.ts:1203 处注入

### 3. 成员生命周期改造（subagent-host + AgentTool 团队分支）
- 专家团模式下 lead 的 `Agent` 调用 = 派工回执（spawn ack 立即返回），成员完成一轮后**不回收**、标记 idle 留在 roster
- 初始 prompt 包成 `<teammate-message teammate_id="team-lead" summary="Initial task assignment for {name}">`（runPromptTurn 团队分支）
- 团队成员路径跳过 `SUMMARY_CONTINUATION`（摘要不再是权威通道）；抑制 AgentBackgroundTask 的终态 notification（结果改走邮箱）；`TaskStop` 映射为强杀成员

### 4. ShutdownCoordinator（新文件 `expert-team/shutdown.ts`）
- `shutdown_request` → pending map（request_id → member + 超时定时器）→ 成员收信后 `shutdown_response(request_id, approve)` → approve 则 abort 成员并出 roster；超时强杀
- `deactivateExpertTeam` 门闩：有活跃成员未走完 shutdown → 报错（session/index.ts:1025 处加检查）

### 5. 提示词重写（expert-team/index.ts）
- 删除两句兼容性文案（"delivered to you automatically" / "compatible transport"）
- Lead：Agent 是异步派工；结果以 `<teammate-message>` 到达；用 SendMessage 纠偏/追问；关团先走 shutdown 协议；只对用户说话
- Member：明文输出对 lead 不可见；必须 SendMessage 交完整结果给 team-lead；收到 shutdown_request 先交结果再 approve

### 6. 持久化与恢复
- roster + pending shutdown + 未投递信件 → session metadata 新字段（`SessionMeta` 旁挂 `expertTeamRuntime`，writeMetadata 链路 session/index.ts:907-915）
- `restoreExpertTeamMode`（session/index.ts:1339-1368）扩展：重建 mailbox、重放 journal；成员对话历史本就持久化、可 resume
